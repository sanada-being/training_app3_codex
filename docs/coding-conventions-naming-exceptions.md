# 命名規約の例外一覧（Issue #79）

## 1. 目的
- `CODING_CONVENTIONS.md` の命名規約を適用したうえで、現時点で例外として維持する項目を明示する。

## 2. 例外一覧

| 対象 | 規約 | 現在の扱い | 理由 |
|---|---|---|---|
| Controllerクラス名 | 接尾辞 `...Control` | `...Controller` を維持 | 既存のMVP/MVC設計と命名一貫性を優先し、横断的な大規模リネームによるノイズを回避するため |
| 既存テストの命名 | テスト関数名は日本語 | 既存の英語メソッド名を維持 | 既存テスト資産の可読性と履歴追跡性を優先し、新規追加分で段階適用するため |
| 既存識別子の接頭辞 | `F` / `v` / `w` の接頭辞 | 既存コードへ一括適用しない | 変更量が大きく、挙動不変確認コストが高いため。新規・局所修正で適用する |

## 3. 運用ルール
- 例外を維持する場合は、PR本文に「対象規約」「理由」「根拠」「将来対応」を明記する。
- 例外の解消を行う場合は、別Issueで影響範囲と回帰確認計画を先に定義する。
