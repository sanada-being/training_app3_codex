# 基本設計書（画面一覧・操作フロー）

## 1. 画面一覧
1. メイン画面
2. 商品管理画面
3. 在庫管理画面
4. 売上登録画面
5. 売上集計画面

## 2. 画面責務
### メイン画面
- 各機能画面への遷移
- CSV読込/保存の入口

### 商品管理画面
- 商品の一覧表示
- 商品の追加/編集/削除
- 商品情報の入力チェック

### 在庫管理画面
- 店舗×商品の在庫一覧表示
- 入荷/出庫処理
- 要発注（在庫5以下）確認

### 売上登録画面
- 販売情報の入力
- 売上登録時の金額計算表示
- 在庫不足時の登録拒否

### 売上集計画面
- 期間指定集計
- 商品別売上金額/数量表示
- 週次合計表示

## 3. 画面遷移
```text
メイン
 ├─ 商品管理
 ├─ 在庫管理
 ├─ 売上登録
 └─ 売上集計
```

## 4. 主要操作フロー
### 4.1 週次運用フロー
1. CSV取込（products / inventory / sales）
2. 商品情報確認・必要時更新
3. 在庫確認・必要時入出庫更新
4. 売上登録（当週分）
5. 集計実行（期間指定）
6. 要発注対象確認
7. 保存（CSV出力 + バックアップ）

### 4.2 商品登録フロー
1. 商品管理画面で新規入力
2. 入力チェック
3. 保存実行
4. 一覧再表示

### 4.3 売上登録フロー
1. 売上登録画面で店舗/商品/数量/日付入力
2. 単価参照と売上金額計算
3. 在庫可否チェック
4. 売上保存 + 在庫減算

## 5. UI共通方針
- 重要操作（削除、上書き保存）は確認ダイアログを表示する。
- 入力エラーはフィールド単位で明示し、保存処理は中断する。
- 非同期処理中は二重実行を防止する。

## 6. 想定データ項目
### 商品
- ProductId
- ProductName
- UnitPrice
- Category

### 在庫
- StoreId
- ProductId
- Stock

### 売上
- SaleDate
- StoreId
- ProductId
- Quantity
- SalesAmount（計算値）
