# データ保護運用ガイド

## 目的
- 誤操作や障害発生時でも、CSVデータを復旧して業務継続できる状態を維持する。

## バックアップ方針
- 対象: `products.csv` / `inventory.csv` / `sales.csv`
- タイミング: CSV上書き直前に自動バックアップを作成
- 保存先: 対象CSVと同一ディレクトリ配下の `_backup`
- 命名: `{元ファイル名}_{yyyyMMdd_HHmmssfff}.csv.bak`
- 世代管理: 自動削除は行わない（運用で定期削除）

## 復元手順（最低限リカバリ）
1. 障害ファイルの配置ディレクトリを確認する。
2. `_backup` 内の最新 `.bak` ファイルを特定する。
3. `CsvDataStore.RestoreLatestBackup(filePath)` を実行する。
4. 復元後に `ReadProducts` / `ReadInventories` / `ReadSales` で読み込み確認する。

## 破壊的操作の確認
- 商品削除は確認ダイアログを必須化。
- 在庫出庫は確認ダイアログを追加し、対象（店舗ID・商品ID・数量）を表示。

## 通知/ログ方針
- ログ出力先: 対象CSVと同一ディレクトリ配下 `logs/operations.log`
- 出力内容:
  - `INFO`: バックアップ作成、書き込み成功
  - `WARN`: バックアップからの復元実行
  - `ERROR`: 書き込み失敗
- UI通知:
  - 入力不備・業務エラーは警告ダイアログ
  - 想定外エラーはエラーダイアログ
