# 利用者向け操作手順書

## 1. 起動
1. アプリを起動する。
2. 画面上部のタブ（商品管理/在庫管理/売上登録/売上集計）から対象業務を選ぶ。

## 2. 商品管理
1. `商品ID` `商品名` `単価` `区分` を入力する。
2. `登録` を押す。
3. 既存商品を更新する場合は一覧から行を選択して `更新`。
4. 削除する場合は一覧から選択して `削除`（確認ダイアログあり）。

## 3. 在庫管理
1. `店舗ID` `商品ID` `数量` を入力する。
2. 入荷は `入荷`、出庫は `出庫` を押す。
3. 一覧で在庫状況を確認する。
4. `要発注（在庫5以下）件数` を確認する。

## 4. 売上登録
1. `販売日` `店舗ID` `商品` `数量` を入力する。
2. 画面上の単価/売上金額見込を確認する。
3. `売上登録` を押す。
4. 登録結果は一覧に反映される。

## 5. 売上集計
1. `開始日` `終了日` を指定する。
2. `集計実行` を押す。
3. 商品別集計・週次集計・合計売上を確認する。
4. `集計結果コピー` で結果をクリップボードへ出力する。

## 6. 障害時の基本対応
1. エラーメッセージを確認する。
2. 必要に応じて運用担当へ連絡し、`docs/data-protection.md` の復元手順を実施する。
