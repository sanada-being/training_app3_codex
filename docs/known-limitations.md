# 既知制約・未対応事項

## 制約
- CSVは単純カンマ区切り実装のため、値中のカンマ/引用符エスケープには未対応。
- データ保存形式はCSVのみ（DB未対応）。
- 単一端末運用前提（複数端末同時更新の競合制御は未対応）。

## 非同期処理
- 非同期化は `CsvDataStore` のI/O APIに適用済み。
- 画面イベント側の全面非同期制御（長時間処理進捗UIの細粒度表示）は今後の改善余地。

## 運用面
- バックアップ世代の自動削除ポリシーは未実装（運用で定期削除が必要）。
- ログローテーションは未実装。

## 将来対応候補
- CSVパーサ強化（RFC4180対応）
- DB移行
- 権限制御/ユーザー認証
- UIの非同期進捗表示とキャンセルUX強化
