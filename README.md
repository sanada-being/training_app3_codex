# training_app3_codex

新人基礎研修向けの販売管理アプリ（WinForms）です。  
商品管理、在庫管理、売上登録、売上集計を扱います。

## 開発/検証コマンド
- `dotnet build "Sales Management App/Sales Management App.slnx"`
- `dotnet test tests/SalesManagementApp.Tests/SalesManagementApp.Tests.csproj`
